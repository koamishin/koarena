Write path — every score is an append-only event

01
Action
Player submits code or a flag.
02
Validate
Zod schema, Clerk session + RBAC, rate limit, language allow-list.
03
Ledger
Insert ScoreEvent with an idempotency key, under a Postgres advisory lock.
04
Snapshot
Recompute totals, upsert ScoreSnapshot with rank.
05
Publish
Update Redis ZSET, publish to the Redis channel.
06
Broadcast
SSE emits score:update; clients invalidate the query.
Invariant: nothing but a ScoreEvent ever writes a score. Any leaderboard can be rebuilt from the event log, so cache loss, disputes and anti-cheat adjudication are all recoverable.
